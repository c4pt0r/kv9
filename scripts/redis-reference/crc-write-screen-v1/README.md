# First CRC write performance screen

See [the report](../../../docs/CRC-WRITE-SCREENING.md). The index binds 95
byte-identical copies from original local evidence. It includes all twelve
client reports and CPU coverage, frozen helpers and contracts, root launch
gates, independent auditing and the derived complete/pooled populations.

The twelve timed cohorts are the first recording; six independent smoke
cohorts precede it. All 17,094,412 measured calls succeed with one attempt.
The original artifacts remain authoritative, including failed ancillary
prelaunch/readback checks. No timing or audit rerun occurred. Large raw WALs
and the complete fixture environment remain local; this compact copy is not
a self-contained rerun environment.

The experiment validates c64 write performance accounting and deterministic
data readback. It does not replace full-history process recovery, actual Chaos
Mesh acceptance, broader workloads or equal-durability comparisons.
