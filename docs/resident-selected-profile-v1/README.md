# Selected resident-index profile evidence

Portable originals for [the CPU attribution report](../RESIDENT-SELECTED-CPU-PROFILE.md).
The archive includes exact harness/engine source snapshots, dependency/archive
verification, plans, build/capture/decode helpers, original failures, the scoped
cache-ownership repair, all five decoded profiles, monotonic spans and final
state identities, call-chain/leaf analysis, disassembly and independent audit.
The four small accepted frame-pointer raw recordings are included. The failed
70.8 MB DWARF recording, large corpus and executables remain local with hashes.

`members.json` gives every uncompressed member identity; `verification.json`
records full archive readback and exclusions. `execution-receipts.json` retains
actual tool terminals, including the first capture supervisor failure. The
failure and low-coverage default recording are not qualified by this packet.

The `static-callback-candidate` subtree is an isolated **unqualified proposal**
from checksum-verified archery 1.2.3, with its original license. Its patch keeps
the pointer callback monomorphic through the existing unwind guard. It has no
accepted proof, tests, performance result or production integration yet. Its
prospective plan states the remaining gates.

These are frame-pointer diagnostic-build component observations, not production
CPU shares, request latency, database throughput, Raft/recovery/Chaos acceptance
or Redis parity. Do not rerun the completed observations without a new question
that requires a changed experiment.
