# FNV writer capacity pilot and generated-cache cleanup evidence

This portable reporting bundle preserves the completed two-object storage pilot and exact Cargo-cache retirement, including original input inventories, source, failures, commands, process/reference checks, retired fingerprint/native completion metadata and actual terminal receipts.

The pilot retains exact raw and legacy compressed roundtrips for both objects; its combined encoded saving was 948,861 bytes. No original was evicted. The cache cleanup's actual filesystem free increase was 11,491,069,952 bytes, with 11,434,840,064 bytes conservatively accounted. All six protected executable hashes matched. Neither result releases a benchmark capacity gate.

Run `python3 verify.py` from this directory to verify every part and reporting member. This is byte integrity verification, without extraction, runtime execution or fresh payload decoding. The source paths and expected hashes remain in `inventory.json`; the archive also contains detailed source aliases and `publication-preparation/omissions.json`.

WAL/data/compressed objects, ELFs/libraries, unrelated histories and old archives remain locally retained and are excluded here. Their existing source/readback hashes are preserved as reporting metadata; this bundle is not a payload backup. Original preparation failures remain failed and identifiable.
