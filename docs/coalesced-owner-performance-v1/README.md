# Coalesced owner performance evidence

The [complete pooled readout](READOUT.md) and [every original repetition](PER-REPEAT.md)
report the accepted four-cell c1/c64 GET-only and mixed GET/PUT screen. See
[the performance report](../COALESCED-OWNER-PERFORMANCE.md) for the decision,
scope, original release identity and next development steps.

Run `python3 docs/coalesced-owner-performance-v1/verify.py` to validate the
reporting archive and top-level readouts against `inventory.json`. This checks
original byte integrity; it does not rerun timing, histories, proofs or audits.

Included are the frozen screen/statistics preparation and contracts, selected
original cohort reports and resource/cleanup receipts, complete independent
audit and numerical derivation, release provenance and reviewed debug-cache
reclamation records. The initial preparation drafts and development failures
remain identified as such. Raw WALs, retained executables and bulky host
observations remain at their original local paths under the accepted inventories.
The separate [validation archive](../coalesced-owner-validation-v1/README.md)
contains formal/source/ordinary-recovery evidence.

All 24 original timed cohorts pass with 49,944,895 measured single-attempt
successes. There was no failed cohort rerun or omitted repetition. C64 GET and
mixed-read behavior improve modestly; c1 GET does not. No actual candidate Chaos,
equal-durability, cross-host, sustained-capacity or significance claim is made.
