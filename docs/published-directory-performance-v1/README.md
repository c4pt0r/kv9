# Original matched write evidence

See [the performance report](../WRITE-PUBLISHED-DIRECTORY-PERFORMANCE.md).
Run `python3 docs/published-directory-performance-v1/verify.py` from the
repository. It hashes every packaged file, streams the entire original
archive to gzip EOF, checks every member and recomputes pooled rates, means
and p99 from the sixteen original timed reports. All eight original smoke
reports remain separate. No archived code is executed and no path is extracted.

The archive retains all 24 reports/configs/final dataset reads, selected
resource, drain and lifecycle records, complete original audit and retention
inventories, independent decoder receipts, frozen helper provenance and
actual root terminals. The original pre-workload Git ownership failure and
the initial derived-summary unit-label issue remain separate from successful
measurement and audit. The corrected summary is also available directly.

Compressed WAL objects, local ELF files and unrelated full-host process dumps
are omitted. The package supports review of the reported measurements; it
cannot rerun the entire local raw-byte retention audit. Full objects and
original local evidence remain preserved. Main stays on CRC; this package
does not establish promotion, Redis parity or cross-host/power-loss durability.
