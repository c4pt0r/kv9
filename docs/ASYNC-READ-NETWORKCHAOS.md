## Observations

- Actual `NetworkChaos` partition selected old leader n1 versus n2/n3, direction `both`. All three victim records report successful injection, and `AllInjected=True` was retained. TCP probes before and after the fault-window client observations showed all four cut directions blocked and both majority directions reachable. A client Pod outside the fault selector continued reaching the public endpoint.
- The targeted public history acknowledged `k=v1` before the fault; majority leader n2 then acknowledged `k=v2`. The same live n1 Pod refused the subsequent read with the exact application record `not_leader=true leader_node_id=unknown`. It did not return stale data. This observation was after deposition; it does not establish a pre-deposition `ReadUnconfirmed` phase. A dead-port transport failure was separately rejected by the typed-refusal predicate.
- After actual NetworkChaos deletion, all six TCP directions were reachable, and the healed quorum read returned v2. All three replicas reached `(term=2, index=125)`, with no fatal state or container restart. Async registry peaks were 1 on all voters, proving the path was used; final async queued/active/in-flight and public in-flight/queued/running/encoded-byte occupancy were all zero. Admitted/completed public request counts balanced.
- The independent concurrent public CLI history has 237 complete calls/returns (212 ok, 25 conservatively unknown). The separate targeted history has 7 (6 ok, 1 conservatively unknown). Fresh copies of both histories, and the merged 244-operation history ordered using their common host monotonic clock, passed the unchanged checker and independent witness replay. A separate stale-success corruption of the recovered v2 read was rejected as invalid.
- Combined outcomes: 218 ok and 26 conservatively unknown. The 26 retain their original results: 15 typed NotLeader responses (13 GET, 2 DELETE), 3 externally timed-out DELETE attempts, and 8 catalog unique-name conflicts. They are not relabeled as 26 definite write failures or as explicit pre-execution admission refusals. Original stdout/stderr, invocation/response order and receipts remain in each JSONL. The workload did not retry uncertain mutations; it continued distinct generated operations.
- Using actual `AllInjected` observation and fault-deletion invocation boundaries, 192 complete operations occurred inside the injected interval: 174 ok and 18 unknown, including 37 successful PUT, 28 GET and 36 SCAN operations. Labels alone are not used to attest fault coverage.
