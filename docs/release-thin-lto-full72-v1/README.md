# ThinLTO full72 reporting evidence

This portable bundle retains every original report and raw histogram for the 72 timed cohorts and the separate 36-cohort smoke, selected configuration/cleanup/resource/drain/identity/retention metadata, frozen runtime and statistics preparation, accepted independent audit inventories, original statistics tables, and actual root terminal receipts. `READOUT.md` and `PER-REPEAT.md` are verbatim copies of the statistics output. All outcomes, attempts, dropped-slot and API/item populations remain in those originals; no new statistics or performance selection is performed by packaging.

`inventory.json` maps every archived source path to its exact decoded size/SHA and lists each compressed part's size/SHA. Parts are at most 2 MiB; reporting members are at most 64 MiB. Run `python3 verify.py` in this directory to check packaged byte identity without extraction. This unchanged verifier checks reporting integrity only; it does not repeat the original acceptance audit or the arithmetic derivation.

WAL/data, `.zst` objects, retained executables, original archive payloads, cache trees, and oversized/non-reporting files are omitted before opening or hashing them. Their original independently accepted inventories/catalogs remain the authority for payload hashes and restore paths. This is **not a payload backup** and cannot independently re-run the full original runtime/retention audit from the portable subset. Large payloads and their original restore authorities remain local. The omissions list records path/type/size-based exclusions; it does not invent a fresh payload SHA. Issue9 API responses and credential material are excluded.

Historical capacity is represented by the original release/terminal/summary authority metadata needed to explain this campaign, without copying earlier campaigns' payloads or mixing their measurements. The first smoke preflight failure, git-trust correction, and subsequent actual smoke/timing/audit/statistics receipts remain separate. A directly completed statistics tool has a null session and its exact direct tool receipt; no numeric session is invented.

Scope remains two forward/reverse 10-second repetitions, point1/batch64 read0/50/100 at c1/c64 on the original three-voter tmpfs fixture. Smoke is excluded from timing. Redis is standalone memory with persistence disabled; write durability is not equal. Complete original tables include tail tradeoffs; no percentiles are averaged and no automatic promotion or significance claim is made here. The retained statistics phrase “codegen only” describes ThinLTO02d relative to its40f parent; the full CRC-to-ThinLTO source comparison also contains the qualified opt-in observer ancestry/default-off refactor. Packaging does not erase that distinction or transfer old diagnostic measurements to these default-feature binaries.
